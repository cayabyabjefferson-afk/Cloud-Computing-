Laboratory Reflection

1. Which cloud infrastructure component do you think is the most important? Why?

I think the compute resource is one of the most important cloud infrastructure components because it provides the processing power needed to run applications, services, and commands. Without compute resources such as CPU and RAM, the other infrastructure components would not be able to perform useful tasks. During the laboratory, I was able to see how CPU and RAM are provided by the Linux environment in KillerCoda.

2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for cloud servers. It allows administrators and cloud engineers to manage compute resources, storage, networking, applications, and system processes through the command line. Linux is also widely used in cloud environments because it is efficient, customizable, and supports many cloud technologies.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of how an infrastructure is designed and configured. It helps cloud engineers understand the resources, services, commands, and configurations that will be used. Good documentation can also reduce mistakes, make troubleshooting easier, and help team members understand the infrastructure before deployment.

4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free -h`, `df -h`, `hostname`, and `ip addr`. I also learned how to identify cloud infrastructure components, compare services from AWS, Azure, and Google Cloud, create a simple cloud infrastructure diagram, and organize technical documentation using Markdown and GitHub.
