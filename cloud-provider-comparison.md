Cloud Provider Comparison

Introduction

Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) are major public cloud providers. Although they use different names for their services, all three provide core infrastructure services for computing, storage, networking, and identity and access management.

Cloud Infrastructure Service Comparison

| Infrastructure Component         | AWS           | Microsoft Azure            | Google Cloud Platform                                                                                                      
| Compute                         | Amazon EC2 – Provides scalable virtual servers for running applications and workloads.                                     | Azure Virtual Machines – Provides scalable virtual machines for Windows and Linux                                            workloads.                         
                                  | Compute Engine – Provides configurable virtual machines and bare-metal instances.                                        
| Storage                         | Amazon S3 – Object storage for storing and retrieving data using buckets.                                                  | Azure Storage / Blob Storage – Cloud storage for objects, files, and other data.                                           | Cloud Storage – Managed object storage that stores data in buckets.                                                       
| Networking                      | Amazon VPC – Provides logically isolated virtual networks where AWS resources can be                                                      deployed.              
                                  | Azure Virtual Network (VNet) – Provides private networking for Azure resources and                                                        communication between resources.  
                                  | Google Cloud VPC – Provides virtual networking for Google Cloud resources.                                                
| Identity and Access Management (IAM)** | AWS IAM – Controls authentication and permissions for AWS resources using                                                  users, roles, and policies. 
                                         | **Microsoft Entra ID / Azure RBAC** – Manages identities and controls access to                                            applications, data, and Azure resources. 
                                         | **Google Cloud IAM** – Controls who can perform which actions on specific Google                                           Cloud resources using roles and permissions. 
### Service Documentation Sources

* AWS EC2: Amazon EC2 provides on-demand and scalable computing capacity through virtual servers.
* AWS S3: Amazon S3 is an object storage service that stores data in buckets.
* AWS VPC: Amazon VPC provides a logically isolated virtual network in AWS.
* AWS IAM: AWS IAM controls authentication and authorization through identities, roles, and policies.
* Azure Virtual Machines: Azure VMs provide on-demand, scalable computing resources for Windows and Linux.
* Azure Storage: Azure Storage provides scalable, durable, highly available cloud storage services.
* Microsoft Entra ID: Microsoft Entra ID manages user identities and controls access to applications, data, and resources.
* Google Compute Engine: Compute Engine provides self-managed virtual machines and bare-metal instances as an IaaS service.
* Google Cloud Storage: Cloud Storage is a scalable managed storage service that stores objects in buckets.
* Google Cloud IAM: Google Cloud IAM controls who can perform which actions on which resources.

1. Which cloud provider offers the broadest range of services? Explain your answer.

-> AWS is generally considered to offer the broadest range of cloud services.** It provides a very large selection of compute, storage, networking, database, security, analytics, AI/ML, and other specialized services, allowing organizations to build many different types of cloud solutions.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

-> Microsoft Azure would be the recommended platform for an organization that primarily uses Microsoft products.** Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID, making it easier for organizations already using the Microsoft ecosystem to manage identities, applications, and resources.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

-> Google Cloud is widely recognized for its AI/ML and Kubernetes capabilities.** Google Cloud provides Vertex AI for training and deploying machine-learning models and AI applications, while Google Kubernetes Engine (GKE) provides a managed Kubernetes platform and includes documentation and capabilities specifically for AI/ML workloads.

4. What similarities did you observe among the three cloud providers?

->All three providers offer equivalent core infrastructure services for compute, storage, networking, and identity and access management.** They also provide scalable virtual machines, cloud storage, virtual networking, security controls, and IAM features, although the names and specific implementations of their services differ.
